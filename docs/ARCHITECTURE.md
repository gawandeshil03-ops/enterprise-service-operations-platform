# Architecture

## High-Level Flow

`
Client -> REST Controllers -> Services -> JPA Repositories -> Relational Database
`

## Study Guide

Review the real source tree and identify:
1. application entry/configuration
2. controller/API layer
3. service/business layer
4. repository/data layer
5. entity/domain model
6. validation/error handling
7. tests
8. Docker/deployment assets

Do not claim an architectural component exists unless it is present in the source.
